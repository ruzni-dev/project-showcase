# frontend-mini-projects

A polished single-page showcase for frontend projects, practice apps, and design experiments.

## What’s included

- A bold landing page for presenting all projects
- Project cards with simple category filtering
- Responsive layout for desktop and mobile
- A design direction that feels more curated than a plain folder of demos

## Files

- [index.html](index.html) - page structure
- [styles.css](styles.css) - visual design and responsive layout
- [script.js](script.js) - project data and filtering logic

## How to use

Open [index.html](index.html) in a browser, or serve the folder with any local static server.

## Best use case

Keep your strongest standalone projects in separate repositories, and use this repo for smaller work, main projects, and design experiments that benefit from being organized in one place.
