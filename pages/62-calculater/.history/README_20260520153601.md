# Calculator Project

A clean, professional front-end calculator project structure with separated assets and clear organization.

## Project Structure

```text
calculater/
|-- index.html
|-- README.md
`-- assets/
	|-- css/
	|   `-- style.css
	`-- js/
		`-- script.js
```

## File Responsibilities

- `index.html`: App markup and layout
- `assets/css/style.css`: Styling, theme, and animations
- `assets/js/script.js`: Calculator logic, history, export, and interactions

## Run Locally

1. Open `index.html` in your browser.
2. Or use VS Code Live Server for auto-reload during development.
